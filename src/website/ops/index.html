How these numbers are produced

  • Deploys: every merge to main runs GitHub Actions with short-lived OIDC credentials, applies the reviewed Terraform plan and runs a smoke test.
  • Drift: every night a read-only terraform plan checks that AWS still matches the code, and opens a GitHub issue if it does not.
  • Uptime: a Lambda loads the site and the API every 5 minutes from outside; the target (SLO) is 99.5% over 30 days.
  • Cost: read from AWS Budgets every 6 hours. Everything runs inside the AWS free tier.
